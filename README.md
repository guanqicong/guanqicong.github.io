# 婚礼游戏优化部署包

## 优化内容

### 1. HTML 体积优化
- **原来**: 1.83 MB（base64 内嵌）
- **优化后**: 13 KB
- **减少**: 99.3%

### 2. 加载策略优化
- **懒加载视频**: 只在进入对应场景时才加载视频
- **进度显示**: 实时显示"加载中 X/5"
- **容错机制**: 图片加载失败不阻塞游戏
- **15秒超时兜底**: 网络慢时自动进入

### 3. 场景切换优化
- **视频懒加载**: 避免一次性加载所有视频
- **自动暂停**: 离开场景时暂停视频
- **预加载提示**: 提前显示下一场景

## 视频文件（需要额外处理）

需要从你的源文件夹复制以下视频到 assets/ 目录：
- start.mp4
- select.mp4
- map.mp4
- thanks.mp4

## 部署步骤

1. 复制视频文件到 assets/ 目录
2. 打包整个 wedding-optimized 文件夹
3. 部署到 CloudBase 或其他静态托管

## 进一步优化建议

### 视频压缩（如果还有卡顿）
```bash
# 使用 ffmpeg 压缩视频
ffmpeg -i start.mp4 -c:v libx264 -crf 28 -preset fast -c:a aac -b:a 64k start_opt.mp4
```

### 启用 CDN 加速
在 CloudBase 控制台开启 CDN 加速，可进一步提升加载速度。
